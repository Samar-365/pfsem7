1. Introduction
1.1 Purpose

The purpose of this project is to create a highly interactive personal portfolio website that showcases the developer's skills, projects, achievements, and experience through cinematic animations powered entirely by Anime.js.

Instead of a conventional scrolling website, the portfolio will feel like an interactive anime-inspired digital experience where every element reacts to user interaction.

The website should demonstrate both frontend development expertise and animation skills.

The portfolio will serve as
